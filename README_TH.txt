เว็บนี้เผยแพร่อยู่ที่ bcsm1989.com

สิ่งที่ปรับ
- 8 หน้า รองรับไทย–อังกฤษ และการจัดวางสำหรับมือถือ
- สีครีม ทราย เหลืองอำพัน น้ำตาล และเขียวมะกอก
- โลโก้ B เดิมปรับเป็นโทน earth tone
- หน้าแรกใช้ภาพเรนเดอร์ด้านหน้า พร้อมระบุว่าโครงการอยู่ระหว่างพัฒนา
- หน้าการชาร์จมีภาพกลางวัน–เย็น และแนวคิดสำหรับรถบรรทุก
- หน้าพื้นที่และบริการใช้ภาพถ่ายจริง พร้อมแกลเลอรีแยกหมวด
- หน้าเดินทางมี Google Maps จากลิงก์ที่เจ้าของสถานีส่งมา
- คงเนื้อหานโยบายความเป็นส่วนตัวและการลบบัญชีจากเว็บเดิม

การนำไปใช้งาน (GitHub Pages — ตั้งค่าแล้ว 10 ต.ค. 2569)
- เว็บ deploy อัตโนมัติทุกครั้งที่ push ขึ้น branch main ผ่าน .github/workflows/pages.yml
  workflow จะรัน build.py + verify.py แล้วนำ dist/ ขึ้น bcsm1989.com
- ไม่ต้องอัปโหลดไฟล์เอง แก้ scripts/build.py (เนื้อหา) หรือ dist/style.css (ธีม) แล้ว commit
- เปิด index,follow แล้ว มี canonical, sitemap.xml และ robots.txt อนุญาตให้ Search Engine เข้าถึง
- ถ้าต้องการซ่อนเว็บชั่วคราว: แก้ "index,follow" ใน build.py เป็น "noindex,nofollow"
- เติมลิงก์แอป ราคา กำลังชาร์จ และวันเปิดให้บริการ เมื่อยืนยันรายละเอียดแล้ว

การแก้ไขต่อ
scripts/build.py คือเทมเพลตสร้างหน้าเว็บ
dist/style.css คือธีมและ responsive layout
dist/app.js คือการเปลี่ยนภาษา เมนู แกลเลอรี และสลับเรนเดอร์
source-original คือสำเนาหน้าเว็บเดิมเพื่อเทียบข้อความ
หลังแก้ไขให้รัน python scripts/build.py แล้ว python scripts/verify.py

การปรับความน่าเชื่อถือ
- เพิ่มหน้าข้อมูลบริษัท พร้อมชื่อบริษัท เลขผู้เสียภาษี และช่องทางติดต่อจากข้อมูลเดิม
- แสดงภาพสถานที่จริงควบคู่กับภาพเรนเดอร์ที่ระบุชัดเจนว่าเป็นแบบแนวคิด
- ชี้แจงสถานะโครงการอยู่ระหว่างพัฒนา และยังไม่ประกาศวันเปิด ราคา และกำลังชาร์จ
- เพิ่มคำถามก่อนเดินทางและปุ่มโทร–นำทางที่เข้าถึงง่ายบนมือถือ
- ปรับธีมครีม ทองหม่น และเขียวเข้มให้เป็นระเบียบและอ่านง่าย
